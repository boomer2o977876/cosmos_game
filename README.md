# 🚀 Космическая Одиссея (Python + Web)

Мультиплатформенный игровой проект, состоящий из трех взаимосвязанных частей:
1. **Python + Pygame**: классическая аркадная игра.
2. **Web Widget (HTML5 Canvas)**: браузерная версия игры с той же физикой.
3. **Космический Ангар**: панель администратора (CRUD) для управления кораблями.

Каждая секунда полёта записывается в «чёрный ящик», а результаты сохраняются в таблицу рекордов (CSV для Python и LocalStorage для Web).

## 📦 Требования

**Для Python-версии:**
- Python **3.10+**
- Pygame **2.x**
- Node.js (для работы JS-физики через `physics_bridge.py`)

**Для Веб-версии:**
- Браузер (Chrome, Firefox, Edge)
- Live Server (рекомендуется для ES-модулей)

Установка зависимостей Python:
```bash
pip install pygame
```
▶️ Запуск
1. Python-версия
Убедитесь, что установлен Node.js, затем запустите:

```bash
python main.py
```
2. Веб-версия
Из-за использования ES-модулей (import/export), браузер заблокирует запуск напрямую через file:///.

Откройте папку в VS Code.

Нажмите правой кнопкой мыши на index.html -> "Open with Live Server".

Или запустите локальный сервер: python -m http.server 8000.

⌨️ Управление
Клавиша	Действие
W	Тяга (ускорение вперёд)
S	Торможение
A / D	Поворот влево / вправо
ESC	Пауза (в веб-версии) / Выход из рекордов (в Python)
🌐 Веб-функционал
Космический Ангар (ЛР 6)
Панель администратора для управления флотом (открывается кнопкой из меню).

Create / Read / Update / Delete: полный цикл управления сущностями.

LocalStorage: мгновенное сохранение всех изменений в JSON.

Валидация: проверка ввода (масса, тяга, прочность).

Поиск: фильтрация списка по названию.

Игровой виджет (ЛР 5)
Интерактивная игра на HTML5 Canvas.

Выбор корабля: характеристики, заданные в Ангаре (тяга, прочность), влияют на геймплей.

HUD: полоска здоровья (HP), счет (время выживания) и скорость.

Таблица полетов: рекорды сохраняются в LocalStorage, сортировка по времени.

Сценарии: возможность вызова функций (godMode, hyperdrive) через консоль браузера.

🕹 Логика игры (Pygame)
Состояния
Главный цикл переключается между четырьмя состояниями: MENU, PLAYING, GAME_OVER, HIGHSCORES.

Игровой процесс
При старте создаются корабль и первая партия астероидов.

Каждый кадр обновляется физика, проверяются коллизии.

Счёт растёт на +1 очко в секунду.

При столкновении игра переходит в GAME_OVER, рекорд сохраняется в CSV.

Параметры астероидов зависят от текущего уровня.

📈 Система уровней
Уровни описаны в space_sectors.json. Уровень повышается каждые level_duration_seconds секунд.
При смене уровня старые астероиды исчезают. В конфиге по умолчанию 5 уровней сложности (от «Спокойного сектора» до «Ядра пояса»).

🛰 Чёрный ящик
Модуль flight_recorder.py раз в секунду пишет в flight_data.log строку:
timestamp | x | y | vx | vy | speed | level

Лог открывается в режиме append с маркерами сессий.

Удобно строить графики траектории.

🏆 Таблица рекордов
Модуль highscores.py ведёт highscores.csv. Хранится топ-50 записей, отсортированных по счёту.
(В веб-версии рекорды хранятся в LocalStorage браузера).

🗂 Структура проекта
```text
├── main.py                  # Точка входа Python-игры
├── settings.py              # Константы (размеры, цвета, скорости)
├── ship.py, asteroid.py     # Классы игровых сущностей
├── button.py, ui.py         # Интерфейс и меню
├── utils.py                 # Вспомогательные функции
├── level_manager.py         # Парсинг уровней
├── flight_recorder.py       # Запись телеметрии
├── highscores.py            # Таблица рекордов
├── physics_bridge.py        # Мост Python <-> Node.js
├── space_sectors.json       # Конфигурация уровней
│
├── physics_js/              # JavaScript-модули
│   ├── physics.js           # Физика для Node.js
│   ├── selftest.js          # Тесты физики
│   ├── web_physics.js       # Физика для браузера (без readline)
│   ├── game.js              # Логика веб-виджета
│   └── index.html           # Интерфейс игры (ЛР 5)
│
├── hangar.html              # Интерфейс Ангара (ЛР 6)
├── hangar.css               # Стили Ангара
├── hangar.js                # CRUD-логика ангара
│
├── flight_data.log          # Лог полёта (создаётся автоматически)
└── highscores.csv           # Рекорды (создаётся автоматически)
```
📚 Описание модулей
Файл	Ответственность
main.py	Связывает всё вместе: события, обновление, отрисовка, состояния
physics_bridge.py	Запускает node physics.js и передает данные через stdin/stdout
physics_js/web_physics.js	Чистая математика для браузера (экспортирует updatePhysics)
hangar.js	CRUD-логика кораблей с сохранением в localStorage
game.js	Игровой цикл requestAnimationFrame, отрисовка Canvas, сценарии
