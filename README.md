# 🚀 Космическая Одиссея

Аркадная игра на **Python + Pygame**: управляй кораблём, уклоняйся от астероидов,
проходи сектора с растущей сложностью и бей рекорды. Каждая секунда полёта

## ⌨️ Управление

| Клавиша | Действие |
|:-------:|----------|
| `W` | Тяга (ускорение вперёд) |
| `S` | Торможение |
| `A` / `D` | Поворот влево / вправо |
| `ESC` | Выход из экрана рекордов |

> Корабль движется по инерции — чтобы остановиться, нужно тормозить.
> Экран «бесконечный»: вылет с одной стороны появляется с противоположной.

## 🕹 Логика игры

### Состояния

Главный цикл переключается между четырьмя состояниями:

| Состояние | Описание |
|-----------|----------|
| **MENU** | Стартовое меню с кнопками `START` / `SCORES` / `QUIT`, звёздным фоном и демо-кораблём |
| **PLAYING** | Основной игровой процесс |
| **GAME_OVER** | Экран проигрыша: финальный счёт, уровень, текущий рекорд, кнопки `RESTART` / `QUIT` |
| **HIGHSCORES** | Таблица топ-10 рекордов из `highscores.csv` с кнопкой `BACK` |

### Игровой процесс

1. При старте создаются корабль в центре экрана и первая половина астероидов
   первого уровня; остальные подсеиваются порциями по `spawn_interval`.
2. Каждый кадр (60 FPS, `dt` ограничен 0.1 с — защита от лагов/паузы окна):
   - считываются нажатия клавиш и применяются к кораблю;
   - обновляются позиции корабля и астероидов;
   - проверяются столкновения (расстояние между центрами < сумма радиусов);
   - тикает таймер уровня, при необходимости спавнятся новые астероиды;
   - раз в секунду пишется запись в «чёрный ящик».
3. **Счёт** растёт на **+1 очко в секунду**, проведённую в игре.
4. При столкновении игра переходит в `GAME_OVER`, рекорд сохраняется в CSV.
5. Количество и параметры астероидов определяются **текущим уровнем**
   (см. [Система уровней](#-система-уровней)).

### Физика

- **Тяга:** `vx += THRUST · cos(α)`, аналогично по `vy` — движение по направлению носа корабля.
- **Торможение:** скорость уменьшается на `BRAKE_THRUST` в направлении движения, пока не обнулится.
- **Астероиды:** летят по прямой с постоянной скоростью под случайным углом;
  скорость и радиус задаются параметрами уровня.

## 📈 Система уровней

Уровни описаны в **`space_sectors.json`** и считываются модулем `level_manager.py`
при запуске игры.

### Структура конфигурации

```json
{
  "sector_name": "Альфа-Центавра",
  "level_duration_seconds": 30,
  "levels": [
    {
      "level": 1,
      "name": "Спокойный сектор",
      "max_asteroids": 6,
      "asteroid_speed_min": 1.0,
      "asteroid_speed_max": 2.0,
      "asteroid_radius_min": 15,
      "asteroid_radius_max": 25,
      "spawn_interval_seconds": 2.0
    }
  ]
}
```

| Поле | Значение |
|------|----------|
| `sector_name` | Название сектора (отображается в HUD и сохраняется в рекордах) |
| `level_duration_seconds` | Сколько секунд длится один уровень |
| `levels[]` | Список уровней (волн) |
| `max_asteroids` | Максимум астероидов на этом уровне |
| `asteroid_speed_min/max` | Диапазон скоростей спавна |
| `asteroid_radius_min/max` | Диапазон радиусов |
| `spawn_interval_seconds` | Пауза между спавнами новых астероидов |

### Поведение

- Уровень повышается **каждые `level_duration_seconds` секунд**.
- При смене уровня старые астероиды исчезают, спавнится первая половина нового лимита,
  остальные подсеиваются по `spawn_interval`.
- После **последнего уровня** игра остаётся на нём — бесконечный «хардкор».
- В HUD отображаются сектор, номер и название уровня, а также **прогресс-бар** до следующего.
- Все параметры можно менять прямо в JSON — перезапуск кода не требуется.

По умолчанию в конфиге **5 уровней**:

| # | Название | Max астероидов | Скорость | Spawn (с) |
|:-:|----------|:--------------:|:--------:|:---------:|
| 1 | Спокойный сектор | 6 | 1.0 – 2.0 | 2.0 |
| 2 | Пояс астероидов | 8 | 1.5 – 3.0 | 1.5 |
| 3 | Метеоритный шторм | 11 | 2.0 – 3.8 | 1.0 |
| 4 | Осколки кометы | 14 | 2.5 – 4.5 | 0.7 |
| 5 | Ядро пояса | 18 | 3.0 – 5.5 | 0.5 |

## 🛰 Чёрный ящик

Модуль `flight_recorder.py` раз в секунду пишет в **`flight_data.log`** строку:

```
timestamp | x | y | vx | vy | speed | level
```

Пример:

```
# === SESSION START 2025-01-15 21:03:11 ===
# timestamp | x | y | vx | vy | speed | level
21:03:12 |   402.31 |   298.77 |   1.203 |  -0.512 |   1.308 | 1
21:03:13 |   403.51 |   298.26 |   1.203 |  -0.512 |   1.308 | 1
...
# === SESSION END 2025-01-15 21:04:47 ===
```

- Лог открывается в режиме **append** — все сессии сохраняются с маркерами `SESSION START/END`.
- Файл корректно закрывается при выходе и при переходе в `GAME_OVER`.
- Удобно строить графики траектории (matplotlib / Excel).

## 🏆 Таблица рекордов

Модуль `highscores.py` ведёт **`highscores.csv`**:

```csv
date,score,level,level_name,sector
2025-01-15 21:03:11,42,3,"Метеоритный шторм","Альфа-Центавра"
2025-01-15 21:05:47,18,2,"Пояс астероидов","Альфа-Центавра"
```

- Файл создаётся автоматически при первой смерти.
- Хранится **топ-50 записей**, отсортированных по счёту по убыванию — старые/слабые обрезаются.
- В меню кнопка **SCORES** открывает топ-10; на `GAME_OVER` показывается текущий рекорд.
- Битые строки CSV (если кто-то правил руками) молча пропускаются — игра не падает.

## 📚 Описание модулей

| Файл | Ответственность |
|------|-----------------|
| `settings.py` | Единое место для констант — цвета, размеры, скорости, физика |
| `ship.py` | Логика и отрисовка корабля: тяга, торможение, пламя, обёртка вокруг экрана |
| `asteroid.py` | Спавн за краем экрана, параметризованные скорость/радиус, кэшированные кратеры |
| `button.py` | Прямоугольные кнопки с закруглением, hover-подсветкой и обработкой кликов |
| `ui.py` | `draw_menu()`, `draw_game_over()`, `draw_highscores()` — UI отдельно от логики |
| `utils.py` | `check_collision(ship, asteroid)` — круговая коллизия по расстоянию между центрами |
| `level_manager.py` | `LevelManager` / `LevelConfig` — парсинг JSON, таймер уровня, смена волн |
| `flight_recorder.py` | `FlightRecorder` — запись координат/скорости раз в секунду, безопасное закрытие |
| `highscores.py` | `HighScores` — чтение/запись CSV, топ-N, обрезка до `max_records`, устойчивость к битым строкам |
| `main.py` | Связывает всё вместе: события, обновление, отрисовка, состояния |
