# 🚀 Космическая Одиссея

Аркадная игра на **Python + Pygame**: управляй кораблём, уклоняйся от астероидов и набирай очки за время в открытом космосе.

## 🎮 Управление

| Клавиша | Действие |
|:-------:|----------|
| `W` | Тяга (ускорение вперёд) |
| `S` | Торможение |
| `A` / `D` | Поворот влево / вправо |

> Корабль движется по инерции — чтобы остановиться, нужно тормозить.
> Экран «бесконечный»: вылет с одной стороны появляется с противоположной.

## 🕹 Логика игры

### Состояния

Игра имеет три состояния, между которыми переключается главный цикл:

| Состояние | Описание |
|-----------|----------|
| **MENU** | Стартовое меню с кнопками `START` / `QUIT`, звёздным фоном и демо-кораблём |
| **PLAYING** | Основной игровой процесс |
| **GAME_OVER** | Экран проигрыша с финальным счётом и кнопками `RESTART` / `QUIT` |

### Игровой процесс

1. При старте создаются корабль в центре экрана и **8 астероидов**, летящих со случайных сторон.
2. Каждый кадр (60 FPS):
   - считываются нажатия клавиш и применяются к кораблю;
   - обновляются позиции корабля и астероидов;
   - проверяются столкновения (расстояние между центрами < сумма радиусов).
3. **Счёт** растёт на **+1 очко в секунду**, проведённую в игре.
4. При столкновении с астероидом игра переходит в `GAME_OVER` и сохраняет финальный счёт.
5. Количество астероидов постоянно поддерживается на уровне `MAX_ASTEROIDS = 8` — новые появляются за краем экрана.

### Физика

- **Тяга:** `vx += THRUST · cos(α)`, аналогично по `vy` — движение по направлению носа корабля.
- **Торможение:** скорость уменьшается на `BRAKE_THRUST` в направлении движения, пока не обнулится.
- **Астероиды:** летят по прямой с постоянной скоростью `ASTEROID_SPEED` под случайным углом.

## 📁 Структура проекта

```
cosmos_game/
├── main.py        # Точка входа, игровой цикл, состояния
├── settings.py    # Все константы (размеры, цвета, скорости)
├── ship.py        # Класс Ship — корабль игрока
├── asteroid.py    # Класс Asteroid — астероид с кратерами
├── button.py      # Класс Button — кнопки UI с hover-эффектом
├── ui.py          # Отрисовка меню и экрана Game Over
├── utils.py       # Вспомогательные функции (проверка коллизий)
└── README.md
```

## 🧩 Описание модулей

| Файл | Ответственность |
|------|-----------------|
| `settings.py` | Единое место для всех констант — цвета, размеры, скорости, параметры физики |
| `ship.py` | Логика и отрисовка корабля: тяга, торможение, пламя, обёртка вокруг экрана |
| `asteroid.py` | Спавн за краем экрана, случайный радиус и направление, отрисовка с кратерами |
| `button.py` | Прямоугольные кнопки с закруглением, hover-подсветкой и обработкой кликов |
| `ui.py` | Функции `draw_menu()` и `draw_game_over()` — отделяют UI от игровой логики |
| `utils.py` | `check_collision(ship, asteroid)` — круговая коллизия по расстоянию между центрами |
| `main.py` | Связывает всё вместе: события, обновление, отрисовка, управление состояниями |

## 💡 Идеи для развития

- 💾 Сохранение рекорда в файл
- 🔫 Стрельба и разрушение астероидов на более мелкие
- 🎁 Бонусы: щит, ускорение, замедление времени
- 🔊 Звуковое сопровождение через `pygame.mixer`
- 🏗 Класс `Game` для инкапсуляции всего состояния игры
- 📊 `Enum` вместо чисел для состояний
